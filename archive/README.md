# Archived documentation material

These files are retained for reference but are not published or run by CI.

- `first-tutorial.md` was a generic Docusaurus starter tutorial with example commands that did not describe the RJM Laird platform. It is retained in case it is useful as a basis for a future real tutorial.
- `generate-remote-manifest-catalogue.mjs` was an unused network-fetching catalogue generator that wrote to the removed `docs/reference/catalogue/` path and imported Zod without declaring it as a direct dependency. It is retained for reference, not as a supported command. If reactivated, define its manifest contracts, dependencies, snapshot policy and destination explicitly first.
