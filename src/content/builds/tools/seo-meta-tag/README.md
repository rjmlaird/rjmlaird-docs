# SEO & Meta Tag Generator

Interactive web utility hosted at **[tools.rjmlaird.co.uk/seo-meta-tag](https://tools.rjmlaird.co.uk/seo-meta-tag)** for constructing, validating, and previewing Open Graph cards, Twitter metadata, schema markup, and standard HTML `<head>` tags in real time.

---

## Technical Overview & Features

* **Real-time Social Previews**: Simulates search engine result pages (SERPs), Twitter/X summary cards, and Open Graph previews across major platforms.
* **Tag Validation**: Ensures character limits for titles ($< 60$ characters) and descriptions ($< 160$ characters) comply with search engine truncation standards.
* **Export Standards**: Generates clean, copy-paste ready HTML snippet blocks and JSON-LD structured data formats.
