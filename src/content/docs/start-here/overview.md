This documentation is the public technical overview and contributor knowledge base for the RJM Laird digital platform. It covers websites, first-party services, external integrations, APIs, data products, deployment and operations. It distinguishes verified implementation from planned work.

## How this site is organised

| Section | Use it to |
| --- | --- |
| [Platform map](/start-here/platform-map/) | Understand the service boundaries and how the main components relate |
| [Terminology](/start-here/terminology/) | Interpret lifecycle, ownership, contract and governance terms consistently |
| [Access and environments](/start-here/access-and-environments/) | Understand contributor access, environments and safe handling of credentials |
| [Platform architecture](/platform/overview/) | Find cross-cutting patterns, governance and durable decisions |
| [Service catalogue](/catalogue/) | Look up first-party capabilities and external providers |
| [Build](/build/configuration/) | Find configuration, deployment and implementation guidance |
| [Operate](/operate/launch-readiness/) | Find ownership, launch checks, incident response and runbooks |
| [Contributing](/contribute/) | Update documentation and validate changes |

## Status and evidence

A hostname or catalogue entry is not proof that a service is deployed. Check the lifecycle, evidence, confidence and last-reviewed date on the canonical service record. Use `To confirm` for unknown details instead of guessing.

## Versions

These docs describe one living version of the estate and are not versioned. Per-tool release notes live in each tool's repository; version-specific instructions use the `Since` marker or tabs.
