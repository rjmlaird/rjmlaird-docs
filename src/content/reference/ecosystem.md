## Maintenance rules

- Keep one project record per maintained system in the Projects section.
- Distinguish repository existence from service availability; neither implies the other.
- Mark uncertain facts as needing review rather than inventing architecture, ownership or uptime claims.
- Update this page when a repository, production URL or lifecycle status changes.
