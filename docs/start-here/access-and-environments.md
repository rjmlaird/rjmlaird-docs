## Requirements

- Node.js 20 or later
- Git

## Install

```bash
git clone https://github.com/rjmlaird/<project>.git
cd <project>
npm install
```

## Verify

```bash
npm test
```

If the tests pass, continue to the [quickstart](quickstart.md).
