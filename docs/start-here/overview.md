# Start here

This documentation is the public technical overview and contributor knowledge base for the RJM Laird digital platform. It covers websites, first-party services, external integrations, APIs, data products, deployment and operations. It distinguishes verified implementation from planned work.

## How this site is organised

| Section | Use it to |
| --- | --- |
| [Platform map](./platform-map.md) | Understand the service boundaries and how the main components relate |
| [Terminology](./terminology.md) | Interpret lifecycle, ownership, contract and governance terms consistently |
| [Access and environments](./access-and-environments.md) | Understand contributor access, environments and safe handling of credentials |
| [Platform architecture](../platform/overview.md) | Find cross-cutting patterns, governance and durable decisions |
| [Service catalogue](../catalogue/index.md) | Look up first-party capabilities and external providers |
| [Build](../build/configuration.md) | Find configuration, deployment and implementation guidance |
| [Operate](../operate/launch-readiness.md) | Find ownership, launch checks, incident response and runbooks |
| [Contributing](./contributing.md) | Update documentation and validate changes |

## Status and evidence

A hostname or catalogue entry is not proof that a service is deployed. Check the lifecycle, evidence, confidence and last-reviewed date on the canonical service record. Use `To confirm` for unknown details instead of guessing.

## Versions

The version dropdown distinguishes the unreleased **Next** documentation from frozen releases, where available. Use the current version for the latest maintained guidance.
