This page takes you from a fresh install to a working result in a few minutes.

## 1. Create a config file

```yaml title="config.yaml"
name: example
log_level: info
```

## 2. Run the project

```bash
npm start -- --config config.yaml
```

## 3. Check the output

You should see a startup message and no errors. If something fails, see [Configuration](../guides/configuration.md).
